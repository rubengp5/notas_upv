# Notas UPV ReExtended

Esta extensión es un fork de [Humanoidear/notas_upv](https://github.com/Humanoidear/notas_upv), que es una adaptación de la extensión [UPV Notas](https://chromewebstore.google.com/detail/upv-notas/bjmnidpncfponneibaficicgamjoeidh) de Chrome para **Firefox** (basado en el código de https://github.com/ToniIvars/notas_upv).

Esta extensión mejora la visualización de las calificaciones en el apartado de notas de la Intranet de la UPV, y añade gráficos estadísticos (bell curve), información personalizada, estadísticas, y opciones de exportación de datos.

### Cambios en este fork

El fork permite cambiar cómo se calculan las estadísticas, pudiendo elegir calcularlas con las notas originales o con las notas normalizadas.
